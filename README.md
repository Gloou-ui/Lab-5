# Лабораторна робота: моделювання феєрверку

## Фізична модель

Кожна частинка після вибуху рухається під дією сили тяжіння. Вісь `y` на
екрані спрямована вниз, тому прискорення вільного падіння має додатний
напрямок:

- `v_y(t + dt) = v_y(t) + g * dt`
- `x(t + dt) = x(t) + v_x(t) * dt`
- `y(t + dt) = y(t) + v_y(t) * dt`

Це чисельна схема Ейлера-Кромера: спочатку оновлюється швидкість, а потім
координати з використанням нової швидкості. Для кожної частинки випадково
обираються напрямок, множник початкової швидкості, колір і тривалість руху.
Після завершення руху частинка поступово зникає протягом 0,8 с і видаляється
з моделі.

## Керування

- **Стрілки вгору/вниз** — збільшити/зменшити початкову швидкість.
- **Стрілки вправо/вліво** — збільшити/зменшити кількість частинок.
- **Пробіл** — призупинити або відновити моделювання.
- **Enter** — повторити вибух із поточними параметрами.
- **Ліва кнопка миші** — перемістити центр і повторити вибух.
- **Esc** — закрити програму.

На екрані показані початкова швидкість, задана й активна кількість частинок
та найбільший радіус хмари від початку поточного вибуху.

## Обчислювальний експеримент

Щоб порівняти вплив параметрів, для кожного запуску зафіксуйте відображений
піковий радіус хмари:

1. Залиште кількість частинок незмінною та проведіть запуски з початковою
   швидкістю 150, 230 і 310 px/s.
2. Поверніть швидкість до 230 px/s і проведіть запуски для 40, 120 і
   200 частинок.
3. Запишіть параметри та піковий радіус у таблицю звіту. Через випадковість
   напрямків повторіть кожен запуск кілька разів і порівняйте середні значення.

Очікувано, більша початкова швидкість збільшує розміри хмари: частинки за
однаковий час проходять більшу відстань. Кількість частинок переважно впливає
на щільність і гладкість хмари, але не на її середній радіус, оскільки
розподіли швидкостей і напрямків залишаються тими самими. Невеликі відмінності
радіуса між запусками зумовлені випадковим вибором напрямків і швидкостей.

## Збирання

Потрібні CMake 3.21 або новіший, компілятор C++17 і vcpkg. Встановіть змінну
середовища `VCPKG_ROOT` на кореневу папку vcpkg, після чого з кореня проєкту
виконайте:

```powershell
cmake --preset default
cmake --build --preset default
```

Для відображення підписів програма завантажує системний шрифт із типових
шляхів Windows, Linux або macOS і повідомляє про помилку, якщо шрифт не знайдено.
